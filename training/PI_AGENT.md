# Orvyth 项目助手（Pi）

已接入官方 `@earendil-works/pi-coding-agent` SDK 1.5.0，由 Python 后端启动独立 Node 进程。继续使用本机 Ollama 和网页版启动时指定的模型。当前默认是 `qwen3:4b-instruct`。

## 使用

1. 重启 `chat_web.cmd`，刷新网页。
2. 点击左侧“项目助手 PI”。
3. 输入项目文件夹的完整路径，例如 `D:\GitHub work\OpenAgent\OpenAgent`。
4. 输入“读取 README.md，概括项目用途和启动方式”，点击“开始任务”。

面板显示实际文件读取记录和流式回答。任务各自使用临时会话，没有跨任务记忆，结果不写入聊天记录；需要保留的回答请自行复制。关闭面板不会立即取消任务，后台最多运行三分钟。

## 换电脑安装

需要 Node.js 22.19 或更新版本、Python 环境、Ollama 和已下载模型。在 `training/pi` 目录运行：

```powershell
npm ci --ignore-scripts
```

依赖锁定在 package-lock.json；node_modules 不提交。Pi 本身采用 MIT 许可，模型的许可另计。当前只请求本机 Ollama，不需要第三方模型密钥。通过原有启动参数 `--model 模型名` 可改用其他已下载模型，但工具调用能力需要实际验证。

## 当前能力和范围

首版提供 `list_project` 和 `read_project`，只读指定目录内文本，解析真实路径以阻止软链接越界；不加载项目或用户的 Pi 扩展、配置、技能、MCP 和指令文件。过滤常见密钥和数据库文件，每次最多12次读取、每文件256KB、输出12000字符。过滤不是通用秘密识别器，普通源码中的敏感内容仍可能送给本机模型。没有写文件或执行命令工具。

本机 Qwen 4B 已实际完成文件读取和版本问答，但出现过名称拼写偏差，不能据此认定复杂任务可靠。如果模型没调用文件工具，界面会标记未核实；超时和模型错误显示任务未完成。后续可增加审核后的文件修改能力。
