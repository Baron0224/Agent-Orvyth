# 原创圆润卡通 3D 小狗预览

独立于聊天程序，仅在本机预览，不读取聊天数据、不调用模型。用户于 2026-11-02 改选圆润橙色、短腿、简单五官、没有写实毛发的卡通风格；尚未替换聊天页。

`model.js` 为原创程序化模型。参考用户截图的造型方向，未下载、使用或分发截图对应的 Sketchfab 模型。通过平滑并集隐式表面与 marching tetrahedra 构造连续的头、脖子、躯干、四肢和耳朵。Root/Spine/Neck/Head 四骨骼及连续蒙皮权重驱动转头，尾巴使用另一个连续网格和五骨骼链。眼睛、鼻子及内耳是附属三维几何。橙色哑光表面、奶油色口鼻与小眼睛取代之前的毛发层和虹膜细节。属于卡通原型，仍待用户评价外观与动作。

保留鼠标跟随、方向键、触摸拖动、点击摸摸、随机看向周围/嗅闻/抬头/摇尾、间隔眨眼。页面隐藏时停止渲染；遵从系统减少动态效果设置。无底部按钮、侧面查看或暂停入口，直接点击宠物互动。射线命中检测区分宠物和空白，触摸拖动与轻点分开处理。需要 WebGL 2。

预览：在上级 dog 目录启动静态服务器，然后访问 `/3d/`；当前本机地址为 http://127.0.0.1:8770/3d/ 。
