# 原创简洁 3D 小狗动作预览

本页独立于聊天程序，只在本机预览，不读取聊天数据、不调用模型。

用户于 2026-11-02 明确选择先用简洁的真 3D 卡通小狗验证自然转头、自主动作，后续细化毛发。旧图片分层方案保留作对比，不接入聊天页。

模型由本项目 `model.js` 原创构建：平滑并集隐式表面，经 marching tetrahedra 生成一张连续皮肤，覆盖头、脖子、躯干、坐姿四肢和耳朵；Root/Spine/Neck/Head 四骨骼和连续蒙皮权重驱动，不旋转或切换头部图片。尾巴另有连续网格及五骨骼链。眼睛、鼻子和内耳为附属三维几何；眨眼通过缩放眼睛实现。外观细化为短身、圆脸、收尖耳朵、深棕虹膜与瞳孔、鼻部细纹、低反光短毛程序化材质和两层稀疏毛边。仍为卡通原型，不是写实逐根毛发或高精度雕刻。

功能：鼠标跟随、方向键、触摸拖动、点击摸摸、随机看向周围/嗅闻/抬头/摇尾、间隔眨眼、减少动态效果、隐藏页停止渲染。2026-11-02 按用户要求移除全部底部按钮和开关，不再提供侧面查看或暂停入口；鼠标跟随和自主动作默认开启。点击采用射线命中，仅点中宠物时触发摸摸，点空白处不触发；触摸拖动和轻点区分处理。WebGL 2 必需。

Three.js 0.180.0 从官方 npm 分发包固定版本复制到 vendor，MIT 许可随附 `vendor/THREE-LICENSE.txt`。代码通过 import map 仅加载本地依赖，运行时无需联网。官方文档：https://threejs.org/docs/ 。
