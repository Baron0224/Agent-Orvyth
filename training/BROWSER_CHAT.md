# Orvyth 浏览器聊天与陪伴空间

白底聊天页面，左侧管理历史聊天，右侧是互动小精灵和待办任务，左下角提供个人资料与设置。

## 启动

保持 Ollama 已启动，在 PowerShell 粘贴：

```powershell
& "D:\GitHub work\OpenAgent\OpenAgent\training\chat_web.cmd"
```

更新这一版后，请先在旧的启动窗口按 Ctrl+C 停止服务，再重新运行命令。浏览器若显示旧页面，按 Ctrl+F5。启动后会自动打开 `http://127.0.0.1:8765/start` 粒子欢迎页，点击文字 **Hi Boss** 进入聊天；没有单独的进入按钮。直接打开 `/` 仍可进入聊天。保持启动窗口开启；端口冲突可添加 `--port 8766` 或 `--port 8772`。

欢迎页用本机 Canvas 绘制银蓝色粒子与细线，前台持续缓慢流动并有轻微鼠标视差，不需要下载视频或访问外部服务。页面进入后台会暂停，回到前台继续；系统启用“减少动态效果”时显示静态画面。页面不支持 Canvas 时仍可点击 Hi Boss 进入聊天。

目前只在本机运行，没有云部署或云费用。其他电脑不能用这个回环地址访问。

## 聊天记录

- 左侧“新建聊天”创建独立对话；点历史标题切换聊天。
- 完成的问答自动保存，首条问题作为初始标题。每条聊天旁的省略号可以改名或删除。
- 顶部“清空”或发送 `/clear` 会在确认后清空当前聊天内容，其他聊天不受影响。
- Enter 发送，Shift+Enter 换行；支持中文输入法和逐步显示回复。
- 不同聊天的模型上下文分开。完整记录可以保存，但模型每次只读取有限的最近上下文。
- 生成失败或中断的未完成问答不会作为完整记录保存，刷新后可能消失。

## 小精灵与任务

小精灵会漂浮、眨眼、跟随光标看向你；点精灵或“摸摸脑袋”会有动作和文字回应。模型思考、回复时精灵会切换状态。“陪我聊聊”会将焦点放到聊天输入框。这些互动是页面动画与本机反馈，不是后台持续调用模型或自动执行任务。

在精灵下方输入任务并按加号即可添加，勾选后进入“已完成”，也能取消勾选或删除。任务由用户手动管理，当前没有定时提醒或自动执行。

窄屏时可用顶部按钮打开聊天列表和“精灵与任务”侧栏。

## 头像与设置

点左下角头像区域展开菜单，选择“设置”，在同一个面板中修改头像、昵称和小精灵选项。“数据与隐私”仍是独立入口。

- 可以修改昵称、选择头像；支持 JPG、PNG、WebP，页面会裁成正方形并缩为 128×128 PNG 后存到本机。
- 可以给精灵改名字、关闭动态效果。系统启用减少动态效果时也会减少动画。
- 昵称、头像和待办不会自动发送给模型。

## 本机数据

从这一版开始，成功完成的聊天、任务和个人设置保存在：

```text
%LOCALAPPDATA%\Orvyth\browser.sqlite3
```

首次启动后创建该文件。浏览器刷新、关闭页面或服务重启不会清空已保存记录。旧版仅在内存中的临时聊天不会自动迁移到数据库。删除聊天或任务会修改本机数据库，页面暂时没有撤销恢复功能；这不是磁盘安全擦除承诺。

已有旧版数据库时，会继续使用 `%LOCALAPPDATA%\OpenAgent\browser.sqlite3`，兼容原来的浏览器身份，避免资料丢失；新安装默认使用 Orvyth 目录。启动窗口会显示实际路径，请以该路径为准备份。磁盘上的项目目录和模型目录暂保留真实旧路径，因此上面的启动命令仍然有效。

不同浏览器资料使用持久 Cookie 区分，同一浏览器标签页共享资料。清除 Cookie 会创建新的本机资料，旧数据库记录不会自动搬移。它不是注册账号或云同步，也没有数据库加密功能。可在服务停止时备份实际数据目录；请不要把这些个人数据提交到 GitHub。

`--data-dir` 可指定其他数据目录。开发测试使用独立临时目录，避免混入实际资料。终端入口 `chat_local.cmd` 仍只保留本次运行的内存历史，和浏览器版保存策略不同。

## 连接与开发

连接失败时先打开 Ollama，再点“检查连接”。缺少模型时按 [本地模型说明](LOCAL_CHAT.md) 准备。当前未联网搜索，模型回答可能有误；模型同时只处理一个网页请求，生成时仍能管理待办或互动小精灵。

后端为 `chat_web.py`，存储为 `browser_store.py`，复用 `chat_local.LocalChat`；页面位于 `browser/`，无需额外依赖。服务仅绑定本机并校验 Host、Origin、数据类型和所有权，不适合直接公开到互联网。正式部署还需要真实账号、权限与资源限制。

验证命令（从仓库根目录运行）：

```powershell
& "training\.venv\Scripts\python.exe" -m unittest discover -s training -p test_chat_web.py -v
node --check training/browser/app.js
```
